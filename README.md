# Фотоохота

Играет песня, на паузе появляется предмет. Игроки фотографируются с ним, модель OpenAI проверяет фото. Первые N засчитанных проходят дальше, остальные выбывают. Раунды идут, пока не останется один игрок.

- `/` страница игрока, на неё ведёт QR-код
- `/host` экран ведущего, его выводят на проектор

## Запуск локально (ПК)

```powershell
python -m pip install --user uv
python -m uv sync
copy .env.example .env   # заполнить OPENAI_API_KEY и PH_HOST_TOKEN
.\.venv\Scripts\python.exe -m uvicorn --factory photo_hunt.app:create_app --host 0.0.0.0 --port 8000
```

Репетиция без OpenAI: `PH_VISION_MODE=fake` в `.env`. В этом режиме засчитывается любое фото.

Камера на телефоне работает только по HTTPS. На мероприятии сервер нужен в облаке с доменом и сертификатом.

## Песни

`data/songs.json` содержит список песен:

```json
{"title": "Название", "item": "кружка", "lyric": "строчка со словом", "file": "song.mp3", "stop_at": 42.5}
```

Файлы песен лежат в `data/music/` и в git не попадают. Если указан `stop_at`, музыка остановится на этой секунде сама. Без него ведущий нажимает «Стоп».

## Проверки (ПК)

```powershell
python -m uv run ruff check
python -m uv run ruff format --check
.\.venv\Scripts\python.exe -m pytest --cov=src --cov-fail-under=60
```

`pytest.exe` блокируется политикой Windows, поэтому тесты запускаются через `python -m pytest`.

Нагрузочный тест: сервер запущен с `PH_VISION_MODE=fake`, затем

```powershell
$env:PH_HOST_TOKEN='<пароль ведущего>'; .\.venv\Scripts\python.exe scripts\load_test.py --players 200
```

## Проверка модели на своих фото (ПК)

Фото раскладываются так:

```
data/eval/кружка/yes/   на фото человек держит кружку
data/eval/кружка/no/    кружки нет, другой предмет или кружка на экране телефона
data/eval/что-то красное/yes/
data/eval/что-то красное/no/
```

Имя папки и есть предмет, который получит модель. Подходят JPG, PNG, WEBP и HEIC с iPhone, размер любой: скрипт сжимает фото так же, как телефон игрока. Папка `data/eval/` в git не попадает.

В `.env` должны быть `OPENAI_API_KEY` и `PH_VISION_MODE=openai`.

```powershell
.\.venv\Scripts\python.exe -m photo_hunt.evaluate data/eval
```

Скрипт выводит вердикт по каждому фото, таблицу по порогам 0.5–0.9 и время ответа, а подробности пишет в `data/eval/report.csv`. Флаг `--burst 50` дополнительно отправляет 50 запросов разом и показывает, сколько не прошло из-за лимитов ключа. Каждый запрос платный.

## Как засчитывается фото

| Ответ модели | Итог |
| --- | --- |
| `match=true`, уверенность от 0.8 | засчитано |
| `match=false`, уверенность от 0.8 | не засчитано, игрок может переснять |
| уверенность ниже 0.8 | решает ведущий |
| ошибка API, таймаут, кривой JSON | решает ведущий |

Если API недоступен, кнопка «Засчитать все спорные» засчитывает спорные фото по времени отправки.

Фото хранятся только в памяти сервера. Фото выбывших удаляются в конце раунда, остальные при перезапуске сервера или по кнопке «Начать новую игру».
