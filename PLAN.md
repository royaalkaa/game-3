# План: Фотоохота

## Итерация 1. Прототип игры

**Зачем.** Проверить, что игра на 100–200 человек работает с телефонов без установки приложения и что модель засчитывает фото без ведущего.

**Что делаем.**
- [x] Логика раундов: музыка, охота, проверка фото, выбывание последних
- [x] Проверка фото через OpenAI, спорные и недоступные уходят ведущему
- [x] Страница игрока: вход по QR, фото с камеры, сжатие до 1024 px
- [x] Экран ведущего: QR, песня с автостопом, предмет, таймер, решения по фото, победители
- [x] Нагрузочный скрипт на 200 игроков

**Критерий приёмки.** 200 игроков с открытым WebSocket одновременно отправляют фото по 200 КБ. Все фото приняты, проверены, и дальше проходит ровно заданное число игроков.

**Тесты.** `tests/test_game.py`, `tests/test_vision.py`, `tests/test_api.py`, `scripts/load_test.py`.

**Что получится.** Игра, в которую можно сыграть локально, и цифры нагрузки.

## Итерация 2. Проверка на реальных фото

**Зачем.** Порог 0.8 и текст запроса подобраны наугад, а модель на реальных фото ещё не проверялась.

**Что делаем.**
- [x] Скрипт прогона `python -m photo_hunt.evaluate`: точность по порогам, время ответа, залп запросов
- [ ] 20–30 своих фото: с предметом, без него, предмет на экране телефона
- [ ] Прогнать их через `gpt-5.4-mini`, замерить точность и время ответа
- [ ] Подобрать порог уверенности и `reasoning_effort`
- [ ] Проверить лимиты ключа OpenAI на 200 запросов за 30 секунд

**Критерий приёмки.** Не меньше 90% верных решений на наборе, медианное время ответа до 3 с.

**Тесты.** `tests/test_evaluate.py` на подсчёт метрик и подготовку фото; сам прогон набора с отчётом.

**Что получится.** Настройки модели, подтверждённые замером.

## Итерация 3. Выезд на мероприятие

**Зачем.** Камера на телефоне работает только по HTTPS, и сервер должен быть доступен из интернета.

**Что делаем.**
- [x] Редактор песен для ведущего (`/songs`): добавить, изменить, удалить, загрузить музыку, отметить секунду остановки во время прослушивания
- [ ] Docker-образ и `compose.yaml` с Caddy: сертификат выпускается сам, домен можно не покупать (`<ip>.sslip.io`). Файлы написаны, сборка образа не проверена.
- [x] `/healthz` для проверки, что сервер жив
- [x] Инструкция по выкладке `DEPLOY.md` и чек-лист репетиции `REHEARSAL.md`
- [ ] Сервер в облаке: арендует владелец, выкладка по `DEPLOY.md`
- [ ] Репетиция с 5–10 живыми телефонами (iPhone и Android)
- [ ] Список песен с секундой остановки и предметами

**Критерий приёмки.** Полная игра с живыми телефонами от QR до победителя без ручных правок на сервере. Песни добавляются через браузер, без доступа к серверу.

**Тесты.** `tests/test_songs.py`, тесты API редактора песен, сборка образа и запуск с Caddy на `localhost`, чек-лист репетиции.

**Что получится.** Готовая к выезду игра.
